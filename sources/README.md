# Gemini Desktop (100% локальный клиент)

Десктопное приложение с интерфейсом в стиле сайта Gemini, работающее полностью локально и отправляющее запросы напрямую в API моделей (`generativelanguage.googleapis.com/v1beta`).

## Возможности
- **Интерфейс как на сайте Gemini**: тёмная и светлая темы, боковая панель с историей чатов, поиск, закрепление и переименование диалогов.
- **Прямой стриминг (SSE)**: мгновенная потоковая генерация через `streamGenerateContent?alt=sse`, кнопка остановки генерации и повторный запуск ответа.
- **Ход мыслей (Thinking)**: сворачиваемый блок рассуждений модели.
- **Мультимодальность**: прикрепление и drag-and-drop изображений, PDF, аудио, видео и файлов с кодом.
- **Панель Canvas**: просмотр кода и интерактивный предпросмотр HTML/SVG прямо внутри окна.
- **100% локально**: API-ключ, настройки и вся история чатов хранятся только на вашем компьютере (никаких сторонних серверов).

## Быстрый старт (2 способа запуска)

### Способ 1: Без установки зависимостей (Python 3)
Откройте терминал в папке `gemini-desktop` и выполните:
```bash
python3 run_local_desktop.py
```
Скрипт поднимет локальный сервер на `127.0.0.1`, сохранит историю в `~/.gemini-desktop/store.json` и откроет приложение в отдельном десктопном окне Chrome/Edge/Chromium (`--app` режим).

### Способ 2: Как нативное Electron-приложение
Требуется установленный Node.js (v18+):
```bash
npm install
npm start
```
Для сборки установщика (`.exe`, `.dmg`, `.AppImage`):
```bash
npm run build:win   # Windows
npm run build:mac   # macOS
npm run build:linux # Linux
```

## Настройка API-ключа
1. Получите ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Нажмите **«Настройки и API»** в левом нижнем углу приложения и вставьте ключ.
3. При необходимости нажмите **«Обновить из API»** в выпадающем списке моделей, чтобы подтянуть все доступные вашему ключу модели.
